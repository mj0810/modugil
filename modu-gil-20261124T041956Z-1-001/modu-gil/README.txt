모두의 길 — 최소 기능 예제

실행
1. index.html을 Chrome 또는 Edge로 엽니다.
2. 인터넷에 연결하면 지도 배경과 지도 라이브러리를 불러옵니다.
3. 필터, 지도/목록, 상세 보기, 엘리베이터 고장 제보를 체험합니다.

구조
- index.html 하나에 HTML(화면), CSS(스타일), JavaScript(동작)가 들어 있습니다.
- 별도의 설치, 빌드, API 키, 회원가입, 서버가 필요하지 않습니다.
- 지도는 Leaflet 1.9.4와 OpenStreetMap을 사용합니다.

구현된 기능
- 엘리베이터·경사로·장애인 화장실 지도 표시 및 유형별 필터
- 예시 위치 또는 사용자가 허용한 현재 위치에서 가까운 순 목록
- 직선거리 표시, 시설 상세 설명, 사진 경로를 추가할 수 있는 구조
- 엘리베이터 고장 제보, 색상/문구 변경, 제보 수와 경과 시간 표시
- 같은 브라우저에서 같은 시설에 5분 이내 중복 제보 방지
- 24시간이 지난 제보는 집계에서 제외
- 저장 실패, 위치 권한 거부, 지도 로딩 실패 안내

확인 방법
1. 엘리베이터 필터를 누르면 2곳이 표시됩니다.
2. 상세 보기에서 고장 제보하기를 누르면 고장 의심 상태와 제보 1건이 표시됩니다.
3. 다시 누르면 중복 제보 안내가 나오며 제보 수는 늘지 않습니다.
4. 창을 닫고 같은 브라우저에서 다시 열면 저장된 제보가 유지됩니다.
5. 화장실 또는 경사로에는 고장 제보 버튼이 표시되지 않습니다.

데이터 수정
- index.html에서 facilities 배열의 name, lat, lng, location, steps를 수정합니다.
- photo에 직접 촬영한 사진의 상대 경로(예: photos/entrance.jpg)를 넣고 photoAlt에 사진 설명을 작성합니다.
- 사진 파일도 함께 전달해야 합니다. 현재 예제에는 현장 사진이 없습니다.
- 현재 6곳은 가상 예시입니다. 공공데이터 API와 연결되어 있지 않습니다.
- 이 예제의 위치와 안내 문구를 실제 이동에 사용하지 마세요.

제한
- 제보는 localStorage에만 저장되므로 다른 사용자나 다른 브라우저와 공유되지 않습니다.
- 중복 방지는 이 브라우저에만 적용됩니다. 저장소 삭제 또는 다른 브라우저 사용을 막지 않습니다.
- 최근 제보가 없다는 것은 정상 작동을 확인했다는 뜻이 아닙니다.
- 거리는 직선거리이며 휠체어 이동 경로·계단 회피·경사도 계산은 구현하지 않았습니다.
- 현재 위치 기능은 브라우저 권한이 필요하며 환경에 따라 HTTPS 또는 localhost가 필요합니다.
- 저장소가 차단된 환경에서는 제보 저장이 실패할 수 있습니다.

실제 서비스로 확장할 때
- 검증한 공공데이터와 현장 사진으로 facilities를 교체합니다.
- 공용 서버와 데이터베이스를 연결해 제보를 공유하고, 서버에서 중복과 유효기간을 검사합니다.
